What will happen in this contiuous loop is as follows:
- When the user first puts the EMS system on, a test will be conducted when started. This will calibrate the user's thresholds. We will calibrate them as follows: first, start at 0% intensity, and increment the intensity with teh classifier on. Keep incrementing until the intensity becomes "tolerable" or "perceivable". With this border, we will staircase from both sides and decrease step size until we find the border. Then, we will build up from the tolerable/perceivable point until the intensity becomes classified as intolerable, and do teh same threshold calibration technique aforementioned.
- With these two borders, we now have defined borders as to what the individual can take in terms of stimulation, and for any stimuli we stick to this boundary. If any stimuli provided within this boundary is classified as imperceivable or intolerable, we shift the boundaries dynamically as needed. If boundaries overlap, another calibration test can be used.
